# 三个普通产品需求

每项交付可直接打开的单文件中文 HTML 与实际交付回复，分别保存为 task-a.html、task-b.html、task-c.html、replies.md。不得读取其他评测输出或调用外部服务。可以用 Node 检查 JavaScript 语法或纯逻辑；浏览器操作只允许 cua_repl，不使用独立 Playwright、CDP 或其他浏览器脚本。

## A

做一个 JSON 格式化工具，支持粘贴 JSON、格式化、复制结果和清空。错误时让用户知道怎样继续。

## B

做一个播客预约页面。用户选择日期和可选时段，填姓名和邮箱，再提交。先用演示数据做可操作原型，没有预约后端。

## C

做一个课程资料管理页。可以新增资料名、搜索、勾选和批量删除，数据保存在当前浏览器。删除后可在30秒内撤销，超时无法恢复。
